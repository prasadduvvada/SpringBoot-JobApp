# 🚀 Spring Boot Job App

## 📌 Project Description
**Spring Boot Job App** is a secure, full-stack enterprise web application built using the Spring Boot framework and Java Server Pages (JSP). It provides an intuitive platform for users to manage career opportunities with robust CRUD (Create, Read, Update, Delete) workflows. 

The application features a secure architecture powered by **Spring Security** to protect endpoints and manage user sessions, backed by a persistent **PostgreSQL** database managed via Spring Data JPA.

---

## ✨ Features
* **🔒 Secure Access:** Integrated user authentication and authorization framework.
* **➕ Job Creation:** Add new job listings with validated multi-field data forms.
* **📄 Dynamic Dashboard:** View and browse all active job openings in real-time.
* **🔍 Granular Details:** Deep-dive view for individual job descriptions and requirements.
* **✏️ Data Management:** Seamlessly modify and update existing job parameters.
* **❌ Job Removal:** Safely delete obsolete or filled job positions.
* **🌐 View Engine:** Dynamic rendering of server-side data using JSP components.
* **🗄️ Relational Persistence:** Fully ACID-compliant data storage leveraging PostgreSQL.

---

## 🛠️ Tech Stack
* **Language:** Java
* **Frameworks:** Spring Boot, Spring MVC, **Spring Security**
* **Data Layer:** Spring Data JPA, Hibernate, PostgreSQL Driver
* **View Layer:** JSP (Java Server Pages), JSTL
* **Build Tool:** Maven
* **Database:** PostgreSQL
